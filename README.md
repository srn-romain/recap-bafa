## 📌 Présentation

**Récap BAFA & BAFD** est une plateforme web gratuite et collaborative conçue pour les animateurs et directeurs en Accueils Collectifs de Mineurs (ACM : séjours de vacances, colonies, ALSH, etc.).

Elle permet de :
- **Centraliser ses expériences** d'animation (organismes, tranches d'âge, types de séjours, durées, etc.).
- **Générer un CV / récapitulatif PDF** d'animation en un clic.
- **Partager son parcours** via une URL personnalisée en consultation sécurisée pour les recruteurs.
- **Calculer des statistiques automatiques** (jours en séjour, nombre de jeunes encadrés, diversité des organismes).
